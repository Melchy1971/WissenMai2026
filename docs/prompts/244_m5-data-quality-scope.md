# Prompt 244 – M5 Data Quality Scope

## Phase
M5 Vorbereitung / Controlled Activation

## Prompt

Entwickle, prüfe oder stabilisiere den Bereich **M5 Data Quality Scope** im Kontext des WissensDB-Masterplans.

Anforderungen:
- Arbeite artefaktbasiert.
- Trenne Feature-Implementierung, Testnachweis, Truth-Validierung, Dokumentation und Gate-Entscheidung.
- Nutze echte PostgreSQL-/Frontend-/Contract-/Governance-Reports, sofern der Prompt einen Gate- oder Truth-Kontext betrifft.
- Keine manuellen Grün-Behauptungen ohne maschinenlesbares Report-Artefakt.
- Dokumentiere Blocker, Risiken, Nachweise und Go/No-Go-Entscheidung.

Output:
- Ergebnisbericht
- betroffene Dateien oder Artefakte
- Tests/Nachweise
- Blocker
- Score oder Gate-Entscheidung, falls relevant
